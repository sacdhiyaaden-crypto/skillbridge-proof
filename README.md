# SkillBridge Proof
live link = https://id-preview--2c313f86-577b-4410-93c9-7217c11933f3.lovable.app/?__lovable_receipt=mat_3rhc3bhj439hwbmzcszt8f6vm6
Build a mobile-first web application called "SkillBridge" that helps workers without formal transcripts validate their real-world competencies through low-barrier assessments.

Design & Aesthetic:

Clean, modern, high-contrast UI using emerald green, slate gray, and crisp white.

Accessible, icon-heavy navigation designed for low-bandwidth mobile users.

User Roles & Core Views (Include a top toggle to switch between roles for demo purposes):

1. Candidate Dashboard ("My Skills & Proof"):

Skill Profile Header: Name, target trade/industry (e.g., Electrical Installation, Software Development, Nursing Assistant), and overall "Verification Score."

4-Way Evidence Builder (Interactive Cards):

Micro-Assessments: Quick, timed scenario-based quizzes with instant pass/fail status.

Practical Trade Proof: A clean upload flow for short video demonstrations or photo evidence of completed work, paired with a checklist of required steps.

Digital Portfolio: A gallery view to showcase past projects, work samples, or client testimonials.

Peer & Employer Vouching: A button to generate a shareable verification link/SMS code that a former boss or colleague can click to endorse specific skills.
